# Applicativo Booking - Neon Pulse

Questa cartella contiene l'applicativo in TypeScript per la prenotazione dei biglietti del festival.

## Funzionalità
- Registrazione nome utente.
- Controllo età dinamico in base al tipo di biglietto (Standard/VIP).
- Limite massimo di 5 biglietti per transazione.
- Feedback immediato all'utente.

## Requisiti Tecnici
- TypeScript per la logica.
- Vite (consigliato per lo sviluppo locale).

## Come avviare
1. Eseguire `npm install` per installare le dipendenze.
2. Eseguire `npm run dev` per avviare l'ambiente di sviluppo.
3. In alternativa, compilare il file `src/main.ts` in JavaScript.
