# Sito Web - Neon Pulse Festival

Questa cartella contiene il sito web informativo per il festival di musica elettronica "Neon Pulse 2026".

## Struttura della Cartella
- `index.html`: Home page.
- `eventi.html`: Programma dell'evento.
- `info.html`: Informazioni logistiche.
- `gallery.html`: Foto dell'evento.
- `registrazione.html`: Pagina con link all'app di prenotazione.
- `style.css`: Foglio di stile globale.
- `DOCUMENTO_ARCHITETTURALE_SITO.md`: Documentazione tecnica del sito.

## Come visualizzare
Aprire il file `index.html` in un qualsiasi browser moderno.
